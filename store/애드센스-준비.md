# GitHub Pages AdSense 준비

웹 광고와 Android 앱은 분리한다. Android 앱에는 광고 SDK와 인터넷 권한을 추가하지
않으며, AdSense는 `https://yongminlee2.github.io/testmin/` 웹 빌드에만 적용한다.

## 저장소 변수

GitHub 저장소의 **Settings → Secrets and variables → Actions → Variables**에 다음 값을
등록하면 다음 Pages 배포부터 자동 적용된다.

| 변수 | 형식 | 용도 |
|---|---|---|
| `ADSENSE_CLIENT_ID` | `ca-pub-숫자` | `<head>`의 사이트 확인 메타와 AdSense 스크립트 |
| `ADSENSE_PUBLISHER_ID` | `pub-숫자` | 배포 루트의 `ads.txt` |

값이 없거나 형식이 틀리면 광고 스크립트와 `ads.txt`를 만들지 않는다. 따라서 승인 전
빌드나 로컬 개발 중에는 Google 광고 요청과 쿠키가 발생하지 않는다.

## AdSense 콘솔에서 할 일

1. 사이트를 등록하고 소유권 확인을 완료한다.
2. 위 두 게시자 값을 저장소 변수에 넣고 Pages를 다시 배포한다.
3. `https://yongminlee2.github.io/testmin/ads.txt`가 콘솔에 나온 값과 일치하는지 확인한다.
4. **개인정보 보호 및 메시지**에서 EEA·영국·스위스용 Google 인증 CMP 메시지를 만든다.
5. 자동 광고를 켠 뒤 모바일에서 문제·선택지·하단 메뉴를 가리는 광고가 없는지 확인한다.
6. 개인정보처리방침의 웹 광고·쿠키 안내가 실제 설정과 계속 일치하는지 확인한다.

## 배포 확인

```bash
npm run build:web
```

`dist/sitemap.xml`은 내보낸 정적 페이지에서 자동 생성된다. 게시자 변수를 임시로 넣어
검증하려면 로컬 환경변수를 사용하되 `.env` 파일은 커밋하지 않는다.

광고 승인에는 코드 설치 외에도 완성된 사이트, 쉬운 탐색, 독창적인 본문이 필요하다.
테스트 문항과 결과 설명은 자체 콘텐츠이며 홈·설정·개인정보처리방침을 통해 목적과 운영
주체를 확인할 수 있도록 유지한다.

공식 확인 문서:

- [AdSense 사이트 준비](https://support.google.com/adsense/answer/7299563)
- [광고 쿠키 개인정보처리방침 필수 내용](https://support.google.com/adsense/answer/1348695)
- [Google 인증 CMP 설정](https://support.google.com/adsense/answer/7670013)
