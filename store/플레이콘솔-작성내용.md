# Google Play Console 작성 내용

앱 버전 `1.0.0`, 패키지 `com.testmin.app` 기준이다. 기능이나 SDK가 바뀌면
이 문서와 개인정보처리방침, 데이터 보안 신고를 함께 갱신한다.

## 앱 콘텐츠

### 개인정보처리방침

`https://yongminlee2.github.io/legal/testmin/privacy.html`

### 광고

- 앱에 광고가 포함되어 있나요? **아니요**
- 현재 광고 SDK와 광고 ID 사용이 없다.

### 앱 액세스

- 모든 기능을 제한 없이 이용할 수 있음
- 로그인, 회원가입, 구독, 초대 코드, 지역 제한 없음
- 심사 계정 또는 별도 안내 불필요

### 타겟층

- 권장 선택: **13~15세, 16~17세, 18세 이상**
- 만 13세 미만 아동을 주 대상으로 디자인하거나 광고하지 않음
- 일반 이용자가 가볍게 즐기는 퀴즈·엔터테인먼트 앱

### 콘텐츠 등급 설문 근거

- 폭력, 유혈, 공포: 없음
- 성적 콘텐츠 또는 노출: 없음
- 욕설 또는 비속어: 없음
- 담배, 주류, 약물: 없음
- 도박 또는 현금성 보상: 없음
- 사용자 제작 콘텐츠와 사용자 간 대화: 없음
- 실제 돈 결제 또는 인앱 구매: 없음
- 위치 공유: 없음
- 연애 관련 심리 문항은 있으나 데이팅·매칭 서비스가 아님

설문의 질문 문구가 바뀌면 실제 앱 화면을 기준으로 다시 답한다.

### 기타 선언

| 질문 | 답 |
|---|---|
| 뉴스 앱 | 아니요 |
| 건강 앱 또는 의료 기능 | 아니요 |
| 정부 앱 | 아니요 |
| 금융 기능 | 아니요 |
| 데이팅 앱 | 아니요 |
| 인앱 구매 | 없음 |
| 계정 생성 | 없음 |

## 데이터 보안

### 데이터 수집 및 공유

- 앱에서 필수 또는 선택적으로 수집하는 사용자 데이터: **없음**
- 제3자와 공유하는 사용자 데이터: **없음**
- 광고 ID, 기기 ID, 위치, 연락처, 사진, 파일, 이메일, 사용 행동 수집: **없음**
- 광고, 분석, 크래시 전송 SDK: **없음**
- Android 인터넷 권한: **없음**

### 기기에만 저장되는 정보

- 응시한 테스트와 하위 유형
- 완료 시각과 결과 요약
- 문제 복원을 위한 무작위 시드
- 오답 문항 식별자, 고른 보기와 정답 보기

위 정보는 앱의 비공개 저장소에만 남고 서버로 전송되지 않는다. 설정에서 기록을
모두 지우거나 앱을 삭제하면 제거된다. 서버 계정이 없으므로 데이터 삭제 요청
기능의 적용 대상이 없다.

### 사용자 주도 공유

사용자가 결과 공유 버튼을 누르면 기기 안에서 결과 이미지가 만들어지고 Android
공유 화면이 열린다. 앱이 공유 대상을 선택하거나 자체 서버로 업로드하지 않는다.
사용자가 고른 외부 앱에서의 처리는 해당 서비스 정책을 따른다.

## 기술 및 출시

| 항목 | 현재 값 |
|---|---|
| 최소 Android | API 24 (Android 7.0) |
| 대상 Android | API 36 |
| 64비트 | arm64-v8a 지원 |
| 네트워크 권한 | 없음 |
| 백업 | `allowBackup=false` |
| 앱 형식 | Play 제출 시 AAB |

프로덕션 AAB는 업로드 키를 연결한 뒤 다음 프로필로 만든다.

```bash
npx eas build --platform android --profile production
```

- production·preview 프로필은 로컬 `credentials.json`과 `testmin-upload.jks`를 사용한다.
- 두 파일과 `keystore.properties`는 저장소에 올리지 않으며 `.gitignore`로 차단한다.
- 로컬 `expo prebuild` 뒤 Gradle 릴리스 빌드도 같은 업로드 키를 사용한다.

### 2026년 정책 대조

- 2026년 8월 31일부터 새 앱과 업데이트는 Android 16(API 36) 이상을 대상으로 해야 한다.
  현재 빌드는 `targetSdkVersion 36`으로 이 기준을 충족한다.
- 2026년 9월 30일부터 Play 패키지는 Android 개발자 인증 요건에 따라 등록되어 있어야 한다.
  Play Console이 `com.testmin.app`을 자동 등록했는지 출시 전에 확인한다.
- 2023년 11월 13일 이후 만든 개인 개발자 계정은 실제 Android 기기 접근 확인과,
  12명이 14일 연속 참여한 비공개 테스트를 마친 뒤 프로덕션 액세스를 신청한다.
- 비공개·공개·프로덕션 트랙은 데이터 보안 양식과 개인정보처리방침이 필요하다.
  내부 테스트 트랙만 데이터 보안 양식 대상에서 제외된다.
