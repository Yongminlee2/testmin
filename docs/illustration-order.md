# 결과 화면 일러스트 발주서 (Codex용)

총 **40장**. 결과 화면에만 쓴다.

## 공통 스펙 (전부 동일)

| 항목 | 값 |
|---|---|
| 형식 | **SVG** (단일 파일, 외부 폰트·이미지 참조 없음) |
| 캔버스 | `viewBox="0 0 400 400"`, 정사각 |
| 배경 | **투명** (앱이 카드 배경색을 깔음) |
| 선 | 검정 `#111111`, 굵기 **6~8** 고정, `stroke-linecap="round"` `stroke-linejoin="round"` |
| 색 | 아래 팔레트 **6색만** 사용. 그라디언트·그림자·투명도 금지 |
| 채색 | 납작한 단색 면 + 검정 외곽선 (코믹/스티커 느낌) |
| 글자 | **넣지 말 것** (앱이 한글 텍스트를 따로 얹음) |
| 인물 | 얼굴은 점 두 개 + 선 하나 수준으로 단순하게. 특정 인종·성별 특징 금지 |

### 팔레트 (이 6색 외 사용 금지)

```
#111111  먹색   — 외곽선 전용
#FFF8E1  크림   — 밝은 면
#FFD43B  노랑
#FF8A5B  코랄
#4ECDC4  민트
#B197FC  라벤더
#74C0FC  하늘
```

### 파일 경로

```
assets/illustrations/personality/<코드>.svg   16장

```

## A. 성격 16유형 — 16장

`assets/illustrations/personality/INTJ.svg` 처럼 **대문자 코드**로 저장.
각 별명이 그대로 그림이 되게. 앱이 별명 텍스트를 밑에 붙이므로 그림만으로 상황이 읽혀야 한다.

| 파일 | 별명 | 그릴 것 |
|---|---|---|
| `INTJ` | 혼자 다 계획해놓고 말 안 하는 사람 | 뒤에 거대한 순서도가 붙은 벽, 앞의 사람은 입을 꾹 다물고 팔짱 |
| `INTP` | 생각만 하다 하루 끝나는 사람 | 의자에 앉은 사람 머리 위로 생각풍선 여러 개가 겹쳐 뒤엉킴, 책상 위 할 일은 그대로 |
| `ENTJ` | 회의 안 잡으면 불안한 사람 | 빈 회의실 화이트보드 앞에서 혼자 손을 들고 있는 사람, 의자는 전부 비어 있음 |
| `ENTP` | 일단 반박부터 하고 보는 사람 | 말풍선 두 개가 서로 부딪혀 번개 모양 스파크, 사람은 신나 보임 |
| `INFJ` | 속으로 다 알면서 모른 척하는 사람 | 눈만 옆으로 흘긋 보는 사람, 머리 위엔 정답을 가리키는 화살표가 떠 있음 |
| `INFP` | 머릿속 세계가 더 바쁜 사람 | 머리 안이 통째로 창문이 되어 그 안에 작은 섬·별·구름 |
| `ENFJ` | 남 챙기다 자기 일 밀리는 사람 | 양손으로 남의 짐 여러 개를 안고 있고, 자기 가방은 발밑에 떨어져 있음 |
| `ENFP` | 판 벌이고 수습 안 하는 사람 | 폭죽·색종이가 터진 한가운데서 웃고 있고, 바닥은 어질러진 채 |
| `ISTJ` | 규칙이 곧 평화인 사람 | 자와 각도기로 반듯하게 줄 맞춘 물건들, 그 앞에서 만족스러운 표정 |
| `ISFJ` | 말없이 다 해놓는 사람 | 개어놓은 빨래·정리된 컵이 쌓여 있고, 사람은 조용히 뒤돌아 나가는 중 |
| `ESTJ` | 안 시켜도 정리하는 사람 | 어수선한 상자 더미를 반듯한 격자로 바꿔놓는 손, 절반은 정리 전/후 대비 |
| `ESFJ` | 단톡방 공지 담당 | 확성기를 든 사람 주위로 말풍선 여러 개가 원형으로 퍼짐 |
| `ISTP` | 말보다 손이 먼저인 사람 | 설명서는 바닥에 던져두고 이미 공구로 분해 중인 손 |
| `ISFP` | 조용히 취향이 확실한 사람 | 똑같은 물건 여러 개 중 딱 하나만 다른 색, 그걸 조용히 집어 드는 손 |
| `ESTP` | 일단 지르고 보는 사람 | 절벽에서 이미 뛰어내린 사람, 낙하산은 아직 펴는 중 |
| `ESFP` | 어디 가든 사진 찍는 사람 | 카메라를 높이 든 사람, 주변이 전부 프레임 모양으로 둘러싸임 |

## C. 급수 배지 — 9장 (전 시험 공용)

`assets/illustrations/grade/1.svg` ~ `9.svg`.
IQ·맞춤법·순우리말·고사성어·MZ·사투리 **모든 정답형 시험이 공유**하므로 특정 과목 소품(한자·도형 등)을 넣지 말 것.

| 파일 | 급수 | 그릴 것 |
|---|---|---|
| `9` | 9급 (최하) | 알에서 막 금이 간 상태, 아직 안 깨짐 |
| `8` | 8급 | 갓 깬 병아리, 껍질 조각이 머리에 얹혀 있음 |
| `7` | 7급 | 병아리가 첫걸음, 발자국 두 개 |
| `6` | 6급 | 작은 리본을 목에 단 병아리 |
| `5` | 5급 | 동메달을 문 병아리 |
| `4` | 4급 | 은메달 + 어깨띠 |
| `3` | 3급 | 금메달, 날개를 펼침 |
| `2` | 2급 | 왕관을 쓴 닭, 트로피 옆에 |
| `1` | 1급 (최상) | 왕관 + 망토 + 트로피, 뒤에 후광 방사선 |

> 9→1로 갈수록 성장하는 한 캐릭터의 연속 단계로 보이게. 캐릭터 비율·색을 9장 내내 통일할 것.
