# IQ 결과의 동물 인지 비유 근거

IQ 결과의 동물 카드는 사람과 동물의 IQ 숫자가 같다는 뜻이 아니다. 서로 다른 종에
사람용 IQ 척도를 그대로 적용할 수 없으므로, 점수대마다 **연구에서 관찰된 인지 강점**을
빌려 재미있는 퍼즐 친구로만 소개한다.

| 결과 친구 | 앱에서 빌린 인지 장면 | 참고 연구 |
|---|---|---|
| 문어 | 팔의 촉각·움직임 정보를 이용한 탐색과 학습 | [Use of Peripheral Sensory Information for Central Nervous Control of Arm Movement by Octopus vulgaris](https://doi.org/10.1016/j.cub.2020.08.037) |
| 라쿤 | 반복 시도, 여러 해결법, 퍼즐 해결의 유연성 | [Wild raccoons demonstrate flexibility and individuality in innovative problem-solving](https://doi.org/10.1098/rspb.2024.0911) |
| 까마귀류 | 도구 선택·변형과 여러 도구의 순차 사용 | [Insightful problem solving and creative tool modification by captive nontool-using rooks](https://pubmed.ncbi.nlm.nih.gov/19478068/) |
| 침팬지 | 화면 숫자의 순서 학습과 가림 뒤 순서 기억 | [Sequence Order in the Range 1 to 19 by Chimpanzees on a Touchscreen Task](https://pubmed.ncbi.nlm.nih.gov/36899632/) |

앱 화면에는 다음 안내를 항상 함께 표시한다.

> 동물과 사람의 IQ 숫자를 비교한 것이 아니며, 연구에서 알려진 인지 강점을 빌린 재미 비유예요.
